One Small Step

Card Reference · 54-row mapping table · 2 identical decks = 108 cards
How to use a card — pick ONE mode when playing:
  ▸ Cash for Money = s   ▸ Invest for R&D = ⌈s/2⌉   ▸ Play identity mode (below).
Strength s: ranks 2–10 = pip · J/Q/K = 10 · A = 12.
Suits 2–10: ♥ Person (crew +⌈s/3⌉, burnable as repair) · ♠ Equipment (repair s, pre-bid +s) · ♦ Bonus (hold: +⌈s/2⌉ to a draw or −repair) · ♣ Extra action (+1 action).
Named band: 9–K ♥ + J–K ♦ = astronauts · 9–K ♣ + J–K ♠ = techs (Person + ability; techs flex: development discount OR mission support).
Aces = Side Missions · Jokers = News Events (roll d6 on the Event Table, page 2).

Phase Difficulty Reference

difficulty = program base + phase offset  (+1 if it's the program's final mission; +2 on every phase of a retried mission).
Program base: Mercury 3 · Gemini 5 · Apollo 7.  Phase offsets: Pre-launch 0 · Launch 0 · Orbit 0 · Splashdown 0 · EVA +1 · Rendezvous +1 · TLI/Coast +1 · Lunar Orbit +1 · Reentry +1 · Landing +2 · Ascent +2.
Outcome: rank + crew + pre-bid ≥ difficulty = Success; below = Minor Failure (pay 3 repair); far below = Major Failure (pay 6 repair). Can't pay = mission fails.

Mission Status Sheet

Campaign ladder · crew pool · turn tracker

Turn Sequence

1. Draw 2 cards → 2. Actions (3: play a card · buy hardware · launch the mission · fly a Side Mission; Extra action cards add +1) → 3. Mission (at most 1 per turn, resolved instantly) → 4. Upkeep (Soviet +1, advance turn).
Year end (every 3rd turn): discard to hand 7, then refill to 7. Crew pool heals. Events trigger whenever drawn — including mid-mission.
